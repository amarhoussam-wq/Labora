# 🏥 LABORA — منصة وتطبيق حجز مواعيد التحاليل الطبية

**LABORA** هي منظومة رقمية متكاملة تربط المرضى بمخابر التحاليل الطبية لتنظيم المواعيد، منع الاكتظاظ، وتسهيل تتبع الفحوصات الطبية. صُمم المشروع كمنتج تجاري واقتصادي قابل للتطوير والعرض في مسابقات ريادة الأعمال والشركات الناشئة (Startup MVP).

---

## 📱 مكونات النظام

1. **تطبيق Android للمريض (`labora.apk`):**
   - إنشاء حساب وتسجيل دخول آمن للمريض.
   - اختيار المخبر الطبي من قائمة المخابر المعتمدة.
   - تدوين التحاليل الطبية المطلوبة يدوياً كما هي مسجلة في الوصفة.
   - إرفاق صورة أو PDF للوصفة الطبية مباشرة عبر كاميرا الهاتف أو المعرض.
   - اختيار اليوم والفترة الزمنية المتاحة وفق نظام سعة آني يمنع التعارض.
   - تتبع فوري لحالة الموعد (قيد الانتظار / مقبول / مرفوض مع توضيح السبب).
   - إمكانية إلغاء الموعد وتحرير الفترة الزمنية.

2. **منصة الويب لإدارة المخبر (`/lab/dashboard.php`):**
   - استقبال فوري لطلبات الحجز الواردة.
   - استعراض بيانات المريض والتحاليل المدونة ومعاينة الوصفة الطبية بأمان.
   - زران لاتخاذ القرار: **قبول وتأكيد الموعد** أو **رفض الموعد مع تدوين السبب**.
   - إدارة الفترات الزمنية والسعة الاستيعابية لكل فترة لتفادي التزاحم.

3. **خادم خلفي وقاعدة بيانات موحدة (REST API + MySQL):**
   - بنية برمجية مبنية بـ PHP و PDO مع استعلامات محمية ضد SQL Injection.
   - قفل معاملات `TRANSACTION ... FOR UPDATE` لمنع الحجز المزدوج.
   - حماية الوثائق الطبية الحساسة ضد الوصول غير المصرح به.

## 🚀 طريقة التثبيت والتشغيل المحلي (Local Setup)

### 1. إعداد السيرفر وقاعدة البيانات:
1. شغّل خادم **Apache** و **MySQL** من لوحة تحكم **XAMPP**.
2. افتح **phpMyAdmin** عبر المتصفح: `http://localhost/phpmyadmin/`.
3. أنشئ قاعدة بيانات باسم `labora` واستورد ملف:
   ```text
   labora.sql
   ```
4. ضع مجلد المشروع داخل مسار:
   ```text
   C:\xampp\htdocs\labora
   ```

### 2. الوصول لمنصة الويب:
- **منصة المخبر الطبي:** `http://localhost/labora/lab/dashboard.php`
- **بوابة المريض (ويب):** `http://localhost/labora/patient/book.php`
- **الصفحة الرئيسية:** `http://localhost/labora/index.php`

---

## 📲 تشغيل تطبيق الأندرويد (`labora.apk`)

1. انقل ملف **`labora.apk`** الموجود في المجلد الرئيسي إلى أي هاتف أندرويد وقم بتثبيته مباشرة.
2. للتوصيل مع حاسوبك الشخصي عبر شبكة الـ Wi-Fi، افتح التطبيق واضغط مطولاً (Long Press) في أي مكان لإدخال عنوان IP حاسوبك:
   ```text
   http://192.168.1.XX/labora/patient/book.php
   ```
3. كود المصدر الكامل لتطبيق الأندرويد موجود داخل مجلدي `android/` و `android_app/`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Backend:** PHP 8 (PDO, Prepared Statements, Secure Session RBAC)
- **Database:** MySQL / MariaDB (Transactions & Foreign Keys)
- **Frontend Web:** Bootstrap 5 RTL, Bootstrap Icons, Font Awesome
- **Mobile App:** Native Android (Java/Kotlin, WebKit FileChooser, RTL Support)
